Test and visit a vertex during Dijkstra's algorithm This function is used to test and visit a vertex w during Dijkstra's algorithm. It takes a mutable priority queue q, an edge e, a vertex w, a residual value residual, and an initial distance value dist_init as inputs. The function updates the distance of the vertex w if a shorter path is found and adds the vertex to the priority queue q.

Parameters
qMutable priority queue of vertices
eEdge connecting the previous vertex to the current vertex
wCurrent vertex being tested
residualResidual capacity of the edge e
dist_initInitial distance value of the current vertex w @Complexity O(log(V)), where V is the number of vertexs in the graph
